# PouchTools v0.1.1

This release turns the original interface prototype into a working local developer toolbox. Every tool is now connected to an operation, and the desktop client provides feedback for successful and invalid input.

## Included tools

- Base64 UTF-8 encode/decode with URL-safe mode, swap, history, copy, clear, and download.
- MD5 hashing for text and files, uppercase/lowercase output, and expected-hash verification.
- Timestamp conversion for seconds and milliseconds with timezone-aware date formatting and a live clock.
- JSON formatting and minification with indentation selection and optional key sorting.
- URL component or full-URI encode/decode with swap and copy actions.
- RFC 4122 version 4 UUID generation for one or more values.

## Desktop experience

- All transformations run locally in the Tauri client.
- Clipboard and download actions include WebView-compatible fallbacks.
- Search, favorites, settings, theme, language, reset, and preference persistence are wired up.
- Closing the window hides the app in the system tray; macOS also hides the Dock icon while hidden.

Installers are built by GitHub Actions for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64. The packages are preview builds and may show platform signing or notarization warnings.
