# PouchTools v0.1.0

PouchTools 的首个桌面预览版本，基于 Rust + Tauri 2，提供统一的开发者工具界面和跨平台安装包。本版主要用于体验桌面交互和验证安装流程，部分工具尚未完成。

## 已提供

- macOS Apple Silicon / Intel、Windows x64、Linux x64 安装包。
- Base64 UTF-8 文本编码与解码、复制和清空。
- 中文 / 英文界面切换、浅色 / 深色主题切换（部分文案尚未翻译）。
- 原生窗口控件，关闭窗口后隐藏到托盘，保留当前页面状态。
- macOS 隐藏窗口后不显示 Dock 图标，通过菜单栏托盘恢复窗口或退出应用。
- 安装包附带 SHA-256 校验文件。

## 下载安装

| 系统 | 选择的安装包 |
| --- | --- |
| macOS Apple Silicon（M 系列芯片） | `PouchTools_0.1.0_aarch64-apple-darwin.dmg` |
| macOS Intel | `PouchTools_0.1.0_x86_64-apple-darwin.dmg` |
| Windows x64 | `PouchTools_0.1.0_x86_64-pc-windows-msvc.exe` 或 `.msi`，任选一种 |
| Linux x64 | `PouchTools_0.1.0_x86_64-unknown-linux-gnu.deb` 或 `.AppImage` |

Linux AppImage 需要添加可执行权限；托盘显示取决于桌面环境对 AppIndicator 的支持。

## 当前限制

- MD5 摘要及时间戳转换页面目前是演示界面，结果为固定示例，不能用于实际计算或校验。MD5 本身不可解密还原。
- JSON 格式化、URL 编解码和 UUID 生成暂为占位入口。
- 搜索、设置、收藏、文件处理、Base64 URL-safe 选项和部分辅助按钮尚未接入。
- 字节统计、转换历史和当前时间仍是示例显示；语言和主题选择暂未持久化。
- macOS 包仅使用 ad-hoc 签名，尚未进行 Developer ID 签名与公证；Windows 包尚未进行 Authenticode 签名。系统可能提示来源或发布者未验证。

建议先体验界面与托盘交互，不要依赖演示功能处理生产数据。
